# Restaurant-Menu
1. Introduction
In today’s digital age, having an online presence is essential for businesses, including restaurants. This project focuses on building a simple, responsive, and visually engaging restaurant website for a fictional brand named HN Fire Kitchen. The goal is to showcase a professional restaurant interface that includes a homepage, menu page, and contact page using only HTML and CSS.

2. Objective
The primary objective of this project is to apply front-end web development skills to create a multi-page website that presents the restaurant's brand, menu, and contact information in a user-friendly format.

3. Technologies Used
•	HTML: For structuring the content and pages.
•	CSS: For styling the web pages and ensuring responsiveness.
